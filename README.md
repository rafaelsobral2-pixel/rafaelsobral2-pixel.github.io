## Projetos

### [Kairós SUS](./kairos-sus) · 2026.2
Plataforma cidadã para reduzir o tempo de espera nas UPAs da Zona Sul de São Paulo. Triagem conversacional pelo WhatsApp (Protocolo de Manchester), roteamento inteligente entre as 11 UPAs e painel preditivo para a gestão (escala NEDOCS).

**Papel**: concepção de produto, pesquisa, modelagem, UI e narrativa  
**Stack modelada**: Java Web · MVC · DAO · Singleton · Strategy · Oracle 19c  
**Dados reais**: CNES/DataSUS · SEADE · InfoDengue (Fiocruz) · INMET · IBGE Censo 2022 · Ouvidoria SMS-SP  
**Entregas**: PDF de 20 slides · vídeo pitch de 3 min · modelagem UML com 13 classes  

### [JOVI Studio](./jovi-studio) · Challenge FIAP × JOVI 2026
Experiência web mobile-first de pós-captura: o usuário seleciona as fotos, o app calcula um Score Visual real (0–100) nos próprios pixels via Canvas, sugere legendas e leva ao compartilhamento. Tudo client-side, sem servidor e sem upload de imagem.

**Stack**: HTML5 · CSS3 · JavaScript vanilla · Tailwind CSS · Canvas API  
**Demo ao vivo**: [rafaelsobral2-pixel.github.io/jovi-studio](https://rafaelsobral2-pixel.github.io/jovi-studio/)  
**Entregas**: app web funcional · MER com 7 entidades (3FN) · apresentação da Sprint 2

## Sobre esse portfolio

Cada projeto aqui tem um **case study** que lê como uma conversa, não como relatório. Em cada um você encontra: o problema, a pesquisa que fiz, as decisões de produto (incluindo o que descartei), a solução proposta e o que faria diferente se recomeçasse hoje.

A ideia é mostrar não só o que foi entregue, mas **como a decisão foi tomada**. Pra isso, cada case inclui trade-offs, fontes e os dados que embasaram cada escolha.

Se algo aqui te interessou ou quer trocar uma ideia sobre produto, SUS, serviços públicos digitais ou carreira, me chama.
